# Init-SPEC 技能包

## 📖 简介

Init-SPEC 是一个用于**系统化项目规划**的 Lingma AI 技能包，帮助用户按照 SPEC 开发范式生成完整的项目开发文档体系。

## 🎯 核心价值

- **规范化**：统一的项目文档标准，便于团队协作
- **系统化**：从需求到测试的完整覆盖，避免遗漏
- **可执行**：详细的伪代码和测试用例，可直接指导开发
- **高质量**：基于最佳实践的文档模板，确保专业性

## 📦 文件结构

```
init-spec/
├── SKILL.md              # 技能定义文件（核心）
├── README.md             # 使用说明（本文件）
└── assets/               # 示例文档模板
    ├── spec-example.md       # 技术规格说明示例
    ├── requirement-example.md # 需求文档示例
    ├── api-example.md        # API设计文档示例
    └── test-example.md       # 测试用例示例
```

## 🚀 快速开始

### 方式一：在 PyCharm + Lingma 中使用

1. **确保技能包位置正确**
   ```
   D:\pycharm\meital\init-spec\
   ```

2. **在对话中触发技能**
   - 输入："帮我规划一个XXX项目"
   - 或："使用 init-spec 技能初始化项目文档"

3. **按引导提供信息**
   - 回答AI关于项目需求的提问
   - 逐步确认每个生成的文档

### 方式二：手动参考模板

如果不想使用AI，也可以直接参考 `assets/` 目录下的示例文件，按照以下顺序编写：

1. `requirement-example.md` → 编写你的 `requirement.md`
2. `spec-example.md` → 编写你的 `spec.md`
3. `api-example.md` → 编写你的 `api.md`
4. `test-example.md` → 编写你的 `test.md`

## 🎓 学习资源

### 示例文档解析

每个示例文件都展示了特定类型项目的文档写法：

- **LLM API 客户端工具**（当前示例）
  - 展示了如何规划一个命令行工具
  - 包含配置管理、API调用、统计功能等
  - 适合作为小型项目的参考模板

### 关键要点

1. **requirement.md** - 关注"做什么"
   - 从用户视角出发
   - 描述功能和价值
   - 提供具体的使用示例

2. **spec.md** - 关注"怎么做"
   - 技术方案选型
   - 系统架构设计
   - 文件和模块划分

3. **api.md** - 关注"如何实现"
   - 详细的函数设计
   - **伪代码是关键**（占60%内容）
   - 参数、返回值、异常处理

4. **test.md** - 关注"如何验证"
   - 单元测试用例表格
   - 集成测试场景
   - 预期输出验证

## ⚙️ 自定义扩展

### 添加新的示例模板

如果你想为特定类型项目创建模板：

1. 在 `assets/` 目录下创建新文件
2. 命名格式：`{项目类型}-{文档类型}-example.md`
3. 例如：`webapp-api-example.md`

### 修改技能行为

编辑 `SKILL.md` 文件中的：
- `执行流程` 部分 - 调整交互步骤
- `注意事项` 部分 - 添加特定规则
- `质量标准` 部分 - 定义验收标准

## 🔧 技术细节

### SKILL.md 格式规范

```yaml
---
name: 技能名称（唯一标识）
description: 技能描述（触发关键词）
tags:
  - 标签1
  - 标签2
version: 版本号
---

# 技能详细说明
...
```

### 元数据字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | ✅ | 技能的唯一标识符 |
| `description` | ✅ | 描述何时触发此技能 |
| `tags` | ❌ | 分类标签，便于检索 |
| `version` | ❌ | 技能版本号 |
