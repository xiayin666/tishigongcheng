# 天气查询功能升级说明

## 📋 更新概述

天气查询功能已从固定城市列表升级为**支持全球任意城市**的网络查询系统。

## ✨ 主要改进

### 1. **全球城市支持**
- ✅ 不再局限于固定的城市列表
- ✅ 支持查询世界上任何有记录的城市
- ✅ 自动通过地理编码API获取城市坐标

### 2. **多语言支持**
- ✅ 支持中文城市名称（如：北京、纽约、伦敦）
- ✅ 支持英文城市名称（如：Beijing、New York、London）
- ✅ 智能识别和转换城市名称

### 3. **智能匹配算法**
- ✅ 基于人口规模的优先级排序
- ✅ 行政级别识别（省会/直辖市优先）
- ✅ 名称精确匹配优化
- ✅ 国家/地区智能判断
- ✅ 国际大都市识别

### 4. **增强的搜索策略**
- ✅ 首次搜索失败时自动重试
- ✅ 中英文双向搜索
- ✅ 模糊匹配支持
- ✅ 多重评分机制确保准确性

## 🔧 技术实现

### API服务
- **地理编码**: Open-Meteo Geocoding API
- **天气数据**: Open-Meteo Weather API
- **优势**: 免费、无需API密钥、全球覆盖

### 智能匹配流程
1. 检查城市名称映射表（中文→英文）
2. 调用地理编码API搜索城市
3. 如果未找到，尝试用原始名称再次搜索
4. 对搜索结果进行多维度评分：
   - 人口规模权重
   - 行政级别权重
   - 名称匹配度权重
   - 国家/地区权重
   - 国际大都市额外加分
5. 选择得分最高的城市
6. 获取该城市的天气数据

### 评分机制详解

```python
# 人口权重
- 百万以上人口城市: 加倍计分
- 限制最大值避免过度影响

# 行政级别
- 直辖市/省会: +5,000,000分

# 名称匹配
- 完全匹配: +8,000,000分
- 部分匹配: +3,000,000分

# 国家匹配
- 明确指定国家: +10,000,000分
- 默认中国城市: +1,000,000分
- 默认美国城市: +800,000分
- 其他主要国家: 400,000-600,000分

# 国际大都市
- 知名城市且人口>500万: +3,000,000分
```

## 💡 使用建议

### 最佳实践
1. **城市名称尽量准确**：使用标准城市名称
2. **可以使用中英文**：系统会自动识别
3. **歧义城市可加国家**：如"美国纽约"vs"英国New York"
4. **小城市也能查**：只要有地理记录即可

### 注意事项
- 需要网络连接
- API超时设置为15秒
- 某些极小城市可能找不到
- 同名城市会根据评分自动选择最可能的
