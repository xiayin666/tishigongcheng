# 链式调用快速开始

## 5分钟上手指南

### 1. 基本使用

```python
from practice05.chained_call_executor import execute_chained_tool_call, load_env_vars
import os

# 加载环境变量
env_vars = load_env_vars('.env')
for key, value in env_vars.items():
    os.environ[key] = value

# 执行链式调用
result = execute_chained_tool_call(
    env_vars, 
    "帮我查询北京的天气",
    max_iterations=5
)

if result["success"]:
    print(result["result"])
```

### 2. 查看执行过程

```python
result = execute_chained_tool_call(
    env_vars, 
    "查询北京和上海天气，比较哪个更适合出行",
    max_iterations=8,
    verbose=True  # 开启详细输出
)

# 访问上下文信息
context = result["context"]
print(f"迭代次数: {context.current_iteration}")
print(f"工具调用: {len(context.call_history)} 次")
```

### 3. 使用中间变量

```python
from practice05.chained_call_context import ChainedCallContext

context = ChainedCallContext(max_iterations=10)

# 存储数据
context.set_variable("weather_data", {...})
context.set_variable("city_name", "Beijing")

# 获取数据
data = context.get_variable("weather_data")

# 查看所有变量
all_vars = context.get_all_variables()
```

### 4. 手动管理上下文

```python
context = ChainedCallContext(max_iterations=5)

while context.can_continue():
    context.next_iteration()
    
    # 执行你的逻辑...
    
    # 记录步骤
    context.add_call_record({
        "tool_name": "my_tool",
        "arguments": {...},
        "result": {...},
        "success": True
    })
    
    # 完成任务
    if done:
        context.complete("最终结果")
        break

# 检查结果
if context.is_completed:
    print(context.final_result)
else:
    print(f"错误: {context.error}")
```

## 常见问题

### Q1: 如何设置最大迭代次数？

```python
# 在创建时设置
context = ChainedCallContext(max_iterations=5)

# 或在执行函数中设置
result = execute_chained_tool_call(
    env_vars,
    request,
    max_iterations=5
)
```

### Q2: 如何添加自定义工具？

在 `chained_call_executor.py` 中添加：

```python
# 1. 导入你的工具函数
from my_module import my_tool

# 2. 添加到可用函数字典
ALL_AVAILABLE_FUNCTIONS["my_tool"] = my_tool

# 3. 添加工具定义
MY_TOOL_DEF = {
    "type": "function",
    "function": {
        "name": "my_tool",
        "description": "工具描述",
        "parameters": {...}
    }
}
ALL_TOOLS_DEFINITION.append(MY_TOOL_DEF)
```

### Q3: 如何处理错误？

```python
result = execute_chained_tool_call(env_vars, request)

if not result["success"]:
    print(f"错误: {result['error']}")
    print(f"上下文: {result['context']}")
```

### Q4: 如何保存和恢复上下文？

```python
# 保存
data = context.to_dict()
import json
with open('context.json', 'w') as f:
    json.dump(data, f)

# 恢复
with open('context.json', 'r') as f:
    data = json.load(f)
context = ChainedCallContext.from_dict(data)
```
